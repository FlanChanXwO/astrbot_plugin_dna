# Agent Tools

Agent Tools 是 AstrBot Agent 可调用的结构化工具，不是聊天命令，不使用命令前缀，也不进入 `commands.json`。

## 启用

通过 Dashboard 配置 `ai.agent_tools_enabled` 控制注册。修改开关后需要重载插件，使 runtime 重新执行 Agent Tools 生命周期。

## 能力范围

工具主要复用玩家查询、体力/周报、日历、图鉴/攻略、兑换码、密函/公告、签到日历等只读能力；签到工具是明确的写操作。工具定义和参数见 [工具入口](../../src/entry/agent_tools/) 与 [领域适配](../../src/modules/agent_tools/)。

支持图片的工具可以通过其当前 schema 请求发送图片；如果图片生成或发送失败，工具应返回明确失败而不是伪造成功。

## 身份与副作用边界

- 用户身份来自当前 AstrBot 原始事件，模型参数不能覆盖当前用户、目标 UID 或 Bot 身份。
- 查询工具不应成为账号、凭据、隐私、订阅或管理员配置的写入口。
- 签到只针对当前消息用户的当前激活 UID，并要求原始消息表达明确的肯定签到意图；否定、疑问或缺少明确意图时不应执行写操作。
- 重复工具调用需要遵守当前实现的幂等/事件边界，不能通过模型自行构造身份参数绕过。

聊天命令见 [命令使用](commands.md)，配置入口见 [配置](configuration.md)。
