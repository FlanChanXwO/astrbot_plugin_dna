# 账号登录

建议在私聊中完成登录。令牌、手机号、验证码和其他登录凭据都不应发送到公开群聊，也不要出现在 Issue、PR、截图或公开日志中。

## 开始登录

默认前缀下发送 `dna登录` 可以进入登录流程。当前命令 registry 还提供 token、手机号验证码以及 UID 管理相关入口；具体语法和权限以 [`commands.json`](../../commands.json) 为准。

登录成功后可以使用帮助/命令清单中的 UID 查看、切换和删除命令管理绑定。玩家查询和签到使用当前激活 UID。

## 登录接入方式

`login.transport` 当前支持：

| 模式 | 用途 |
| --- | --- |
| `local` | 使用插件内置登录服务 |
| `http_poll` | 通过外置服务轮询结果 |
| `sse` | 通过外置服务接收 SSE 回执 |
| `ws` | 通过外置服务接收 WebSocket 回执 |

相关地址、监听、共享密钥和绑定上限等字段以 [`_conf_schema.json`](../../_conf_schema.json) 为准。

`local` 模式跨设备使用时，浏览器必须能够访问配置的公开地址/监听端口。外置模式则需要确保 URL、transport 和共享密钥属于同一套服务配置。

## 内置登录页背景

`local` 模式默认尝试使用公共资源快照中的 MP4 动态背景和循环 MP3 音乐。`login.dynamic_background` 关闭时，页面不会请求媒体地址，继续使用当前静态背景。音频与动态背景共用这一开关，默认音量为 35%，页面右下角按钮可以启动、静音或恢复音乐。

以下情况会自动保留静态登录背景，不影响手机号、验证码和提交流程：

- 资源快照还没有完整的登录媒体，或 MP4/MP3 文件头校验失败；
- 视频或音频加载失败；
- 浏览器开启了“减少动态效果”（`prefers-reduced-motion: reduce`）。

浏览器禁止自动播放音乐时，视频仍可继续播放；点击右下角音乐按钮即可尝试启动音频。外置 `dna-login` 服务不使用这组内置媒体路由。

## 登录状态与隐私

“已绑定游戏账号”不等于“拥有 AstrBot 管理权限”。同样，隐私规则也不会因为切换 UID 自动失效。查询他人信息时仍会执行当前隐私与目标解析规则。

插件数据目录可能包含可用于访问账号的敏感信息。备份、迁移或排障时应把整个目录视为敏感数据，不上传到公开位置。

## 排障

登录失败时按以下顺序检查：

1. 当前插件配置中的 `login.*` 是否与使用的接入方式匹配；
2. `local` 模式的地址/端口是否可从浏览器访问；
3. 外置模式的服务、网络与共享密钥是否匹配；
4. AstrBot 日志中是否有明确的网络、过期、取消或上游错误类别。

反馈问题时提供 AstrBot/插件版本、最小复现步骤和已脱敏错误即可，不要提供原始凭据。
