# Dashboard 管理页

插件管理页面由 AstrBot Dashboard 承载，通过插件注册的 Web 路由访问。管理能力应依赖 Dashboard 的已认证上下文，不提供独立的公开管理入口。

## 当前功能范围

管理页当前主要覆盖：

- 定时任务、投递目标与群成员探测；
- 全局账号/绑定状态和玩家卡片预览；
- 角色、武器自定义别名维护。

具体页面和接口以 `pages/dashboard/`、`src/entry/admin_web.py`、`src/entry/web.py` 为准，本页不复制路由清单。

## 操作边界

- 任务页管理已有任务/投递状态，不应把页面当作任意任务执行器。
- 账号和预览操作会访问敏感账号状态；管理员应在受控浏览器中使用，不把页面内容截图或转发到公开位置。
- 群成员探测依赖当前平台提供的群成员能力。能力不可用或结果不确定时，不应把 `unknown` 等同于成员已离群。
- 默认别名来自公共资源，自定义别名属于运行期数据。公共资源说明见 [公共资源](resources.md)。

## 删除与其他破坏性操作

执行账号、任务目标或自定义数据的删除前，先阅读页面返回的预览/确认信息，并确保实际部署环境有符合需要的备份。跨数据库、JSON 或外部平台的操作可能无法形成单一事务，因此应以服务端逐项结果为准。

若页面行为与本文不一致，以当前代码和返回结果为准，并同步修正文档。
