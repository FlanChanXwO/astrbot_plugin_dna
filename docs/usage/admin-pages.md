# Dashboard 管理页

管理页通过 AstrBot Dashboard 的插件入口打开，只接受已登录的 Dashboard 管理员身份。页面中的
写操作会显示确认提示，完成后重新读取服务端状态；未通过认证的请求不会被当作成功。
页面品牌名称优先读取 AstrBot 原生页面桥接上下文中的 `displayName`，独立预览或桥接上下文不可用时
使用 `DNAUID（二重螺旋）`。

## 功能区

当前管理页包含：

1. 定时任务、投递目标和群成员探测；
2. 全局账号、玩家绑定和卡片预览；
3. 角色与武器别名维护。

页面不创建新的任务类型或账号，不提供独立的未认证入口。插件版本显示来自根目录的
`metadata.yaml`。页面左上角和移动端顶部使用 `pages/dashboard/logo.png`，该文件与插件根目录品牌
资源保持一致。

## 表格与分页

任务仍一次性展示全部内置任务；投递目标、账号、角色别名和成员探测结果使用服务端分页。分页 DTO
统一返回 `items`、`page`、`page_size`、`total` 和 `total_pages`，页码从 1 开始，页大小只接受
10、20、50，默认每页 20 行。空结果的 `total_pages` 为 0，不伪造占位数据。

- 投递目标先按当前选择的任务过滤，再按目标 ID、来源、群、UID 等字段搜索和分页；
- 账号按单个 `(user_id, uid)` 绑定分页，搜索只匹配 `user_id` 与 UID；列表只读取凭据状态，编辑时
  才在居中模态框中读取完整凭据；
- 角色别名按角色分页，搜索 canonical name、默认别名、自定义别名和生效别名；完整列表在居中
  模态框中查看，默认别名只读；
- 成员探测接口只分页当前返回的群结果，`all_absent`、`has_present`、`has_unknown`、
  `has_unsupported` 和 `can_delete_user` 始终来自完整探测结果。

搜索提交和页大小变化会回到第 1 页。服务端响应为空且当前页超出最后一页时，页面自动回到最后一个
有效页；快速切换页码或搜索时，旧请求不会覆盖较新的结果。移动端表格会折行为带字段标签的响应式
行，不改用大卡片堆叠。

## 全局账号与玩家预览

账号绑定按用户和 UID 管理，同一用户在不同 AstrBot 平台上使用同一组绑定。账号列表默认只显示
UID、激活状态、来源和登录状态摘要，不在列表中展示原始登录内容。

管理员可以打开已有账号，查看玩家概览或角色详情卡片。凭据编辑、预览和详情参数均在居中模态框中
完成；预览使用目标账号的当前登录状态，并沿用服务端返回的 base64 图片数据流，不会把图片或凭据
写入浏览器存储。预览不会修改个人隐私设置；如果账号未登录、上游不可用或图片服务不可用，页面
会返回明确错误。

账号删除会清理该用户的绑定、个人隐私设置、相关订阅和签到记录。群组规则、群组订阅和其他
用户的绑定不会随之删除。涉及多个存储位置的操作会逐项返回结果，遇到失败时请按结果重试。

## 任务与投递目标

页面展示内置签到、密函、公告和清理任务的状态、调度时间与投递目标。可以暂停或恢复已有任务，
但不会创建自定义任务。密函推送时间由 `notifications.secret_push_minute` 控制；公告推送还受
`notifications.announcement_enabled` 和 `notifications.announcement_check_minutes` 影响。

公告目标通常由聊天订阅命令建立。删除或停用目标前请确认群聊或会话范围；操作完成后可回到
[命令说明](commands.md) 查看对应订阅命令。

## 群成员探测

成员探测需要当前平台提供 OneBot V11 的群成员列表能力。页面会先检查能力状态：

- `present`：确认成员仍在群中；
- `absent`：确认成员已离群；
- `unknown`：平台不支持、网络失败或响应不完整。

只有明确的 `absent` 结果可以触发单群清理；全局清理会重新检查所有关联群，出现 `present`、
`unknown` 或能力不可用时会停止操作，不把不确定结果当作离群。分页只影响当前页面展示，不影响
这组全局安全判断。

## 别名维护

默认角色和武器别名来自公共资源，只读不可替换。管理员可以通过聊天命令或管理页维护自定义别名，
并使用 `恢复别名` 保留自定义内容地重新载入默认别名，或使用 `强制恢复别名` 清空自定义内容。
管理页的角色行只展示默认、自定义和生效别名数量；完整内容通过模态框查看和编辑。资源同步说明
见 [公共资源](resources.md)。

## 数据与安全

管理 API 继续返回 `Cache-Control: no-store`。管理页不会把账号数据或凭据写入浏览器存储。管理员
仍应避免截图、录屏、复制或转发包含账号状态的页面；反馈问题时只提交经过脱敏的错误信息。

插件运行期数据位于 `StarTools.get_data_dir("astrbot_plugin_dnaby")`。执行账号删除、任务删除或
别名清理前，建议先备份插件数据目录；备份应限制访问，不要提交到 Git 或上传到公开位置。
