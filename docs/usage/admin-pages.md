# Dashboard 管理页

插件管理页面由 AstrBot Dashboard 承载，通过插件注册的 Web 路由访问。管理能力依赖 Dashboard 的已认证上下文，不提供独立的公开管理入口。页面品牌名称优先读取 AstrBot 原生页面桥接上下文中的 `displayName`；桥接上下文不可用时使用插件当前显示名“狩月终端”。

## 当前功能范围

管理页当前主要覆盖：

- 定时任务、投递目标与群成员探测；
- 全局账号/绑定状态和玩家卡片预览；
- 角色、武器自定义别名维护。

页面不创建新的任务类型或账号。插件版本显示来自根目录的 `metadata.yaml`。页面左上角和移动端顶部使用 `pages/dashboard/logo.png`。

具体页面和接口以 `pages/dashboard/`、`src/entry/admin_web.py`、`src/entry/web.py` 为准，本页不复制路由清单。

## 表格与分页

任务仍一次性展示全部内置任务；投递目标、账号、角色别名和成员探测结果使用服务端分页。分页 DTO 统一返回 `items`、`page`、`page_size`、`total` 和 `total_pages`，页码从 1 开始，页大小只接受 10、20、50，默认每页 20 行。空结果的 `total_pages` 为 0。

- 投递目标先按当前选择的任务过滤，再按目标 ID、来源、群、UID 等字段搜索和分页；
- 账号按单个 `(user_id, uid)` 绑定分页，搜索匹配 `user_id` 与 UID；列表只读取凭据状态，编辑时才在模态框中读取完整凭据；
- 角色别名按角色分页，搜索 canonical name、默认别名、自定义别名和生效别名；完整列表在模态框中查看，默认别名只读；
- 成员探测接口只分页当前返回的群结果，删除安全判断仍基于完整探测结果。

搜索提交和页大小变化会回到第 1 页。服务端响应为空且当前页超出最后一页时，页面会回到最后一个有效页；快速切换页码或搜索时，旧请求不会覆盖较新的结果。移动端表格会折行为带字段标签的响应式行。

## 操作边界

- 任务页管理已有任务/投递状态，不应把页面当作任意任务执行器。
- 账号和预览操作会访问敏感账号状态；管理员应在受控浏览器中使用，不把页面内容截图或转发到公开位置。
- 群成员探测依赖当前平台提供的群成员能力。能力不可用或结果不确定时，不应把 `unknown` 等同于成员已离群。
- 默认别名来自公共资源，自定义别名属于运行期数据。公共资源说明见 [公共资源](resources.md)。

管理员可以打开已有账号，查看玩家概览或角色详情卡片。凭据编辑、预览和详情参数均在模态框中完成；预览使用目标账号的当前登录状态，并沿用服务端返回的 base64 图片数据流，不会把图片或凭据写入浏览器存储。预览不会修改个人隐私设置。

## 删除与其他破坏性操作

执行账号、任务目标或自定义数据的删除前，先阅读页面返回的预览/确认信息，并确保实际部署环境有符合需要的备份。跨数据库、JSON 或外部平台的操作可能无法形成单一事务，因此应以服务端逐项结果为准。

## 任务与投递目标

页面展示内置签到、密函、公告和清理任务的状态、调度时间与投递目标。可以暂停或恢复已有任务，但不会创建自定义任务。删除或停用目标前请确认群聊或会话范围；对应订阅命令见 [命令说明](commands.md)。

## 群成员探测

成员探测需要当前平台提供群成员列表能力。页面区分 `present`、`absent` 与 `unknown`。只有明确的 `absent` 结果可以触发单群清理；全局清理会重新检查所有关联群，出现 `present`、`unknown` 或能力不可用时会停止操作。分页只影响页面展示，不影响这组全局安全判断。

## 别名维护

默认角色和武器别名来自公共资源，只读不可替换。管理员可以通过聊天命令或管理页维护自定义别名，并使用恢复操作重新载入默认别名。资源同步说明见 [公共资源](resources.md)。

## 数据与安全

管理 API 返回 `Cache-Control: no-store`。管理页不会把账号数据或凭据写入浏览器存储。插件运行期数据位于 `StarTools.get_data_dir("astrbot_plugin_dna")`。执行账号删除、任务删除或别名清理前，建议先备份插件数据目录；备份应限制访问，不要提交到 Git 或上传到公开位置。

若页面行为与本文不一致，以当前代码和返回结果为准，并同步修正文档。
