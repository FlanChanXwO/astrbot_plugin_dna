# 命令

插件默认命令前缀为 `kk`，例如 `kk帮助`、`kk签到`、`kk登录`。实际触发前缀以 Dashboard 的
`display.command_prefixes` 为准；下文命令主体省略前缀，发送时请在主体前加上当前配置的前缀。

当前清单包含 64 条命令，覆盖账号、玩家信息、图鉴、攻略、签到、密函、公告、兑换码、隐私、别名、公共资源和客户端更新。完整的正则、示例和权限以 [`commands.json`](../../commands.json) 为准，发送 `帮助` 可以查看当前实例的帮助卡片。

## Agent Tools

Agent Tools 是独立的结构化工具，不属于聊天命令，不使用命令前缀，也不会出现在聊天帮助中。它们
由 `agent_tools.enabled` 控制，默认关闭；启用方式和工具列表见 [Agent Tools 使用说明](agent-tools.md)。

## 账号与登录

- `登录`、`登陆`、`登入`、`登龙`、`login`：启动登录页并返回链接。
- `登录<token>`：使用令牌登录，例如 `登录<token>`。
- `token登录<token>`、`登录token<token>`：使用显式令牌登录入口。
- `登录手机号,验证码`：使用手机号和验证码完成 App 登录。
- `退出登录`、`登出`、`logout`：退出当前激活 UID。
- `切换<13位UID>`、`删除<13位UID>`：切换或删除一个已绑定 UID。
- `删除全部UID`、`查看UID`：删除全部绑定或查看当前绑定列表。
- `获取ck`、`获取Token`：只查看登录凭据的保存状态，不在回复中展示原始凭据。

登录方式支持 `local`、`http_poll`、`sse`、`ws`，详细行为见 [账号登录](login.md)。建议在私聊中完成登录，不要把登录参数发送到公开群聊。

## 玩家信息与缓存

- `查询`、`卡片`、`角色`、`信息`：查看当前 UID 的角色、近战武器和远程武器概览。
- `<角色名>面板`、`<角色名>信息`、`<角色名>详情`、`<角色名>面包`、`<角色名>🍞`：查看角色属性、技能、溯源、魔之楔和武器详情；可追加一把近战武器和一把远程武器。
- `刷新`、`清理`及批量/管理员刷新形式属于面板管理命令，不会被角色详情命令当作角色名。
- `刷新<角色名>面板`：刷新当前 UID 的指定角色，并固定发送新的完整卡片。
- `刷新全部角色面板`：刷新当前 UID 的概览和已解锁角色，并返回汇总结果。
- `清理<角色名>面板缓存`：清理指定角色数据和卡片缓存，保留概览缓存。
- `清理全部角色缓存`：清理当前 UID 的玩家数据和卡片缓存。
- `刷新<游戏UID>的<角色名>面板`：管理员按指定游戏 UID 刷新角色面板。

玩家图片由 AstrBot 的公共图片响应发送，生成文件写入
`StarTools.get_data_dir("astrbot_plugin_dnaby")/rendered/`。缺少图片资源时会返回明确的缺失状态，不会把插件源码目录当作运行期写入位置。

## 资料、图鉴与攻略

- `每日`、`mr`、`便笺`、`体力`、`日常`：查看实时便笺和锻造状态。
- `周报`、`本周周报`、`上周周报`：查看本周或上周的资源统计。
- `日历`：查看活动日历，不修改账号数据。
- `<名称>图鉴`、`<名称>wiki`：查看角色、武器或魔灵图鉴。
- `<角色名>攻略`：查看角色攻略图片。
- `兑换码`、`cdk`、`code`：查看当前有效的兑换码。
- `<角色/武器名>别名`：查看别名列表。
- `角色列表`、`武器列表`：查看可用的角色或武器名称。

## 客户端更新命令

- `客户端更新`：查询国服 PC 和安卓最新客户端版本；`客户端更新 PC` 或 `客户端更新 安卓`
  只查询指定平台。查询只读，不改变轮询任务维护的基线。
- `订阅客户端更新`：由群聊管理员为当前群订阅全部平台；追加 `PC` 或 `安卓` 可只订阅一个平台。
  `取消订阅客户端更新`：取消当前群的客户端更新订阅。
- 订阅按当前会话目标保存，平台选择写入 `Subscription.extra_data` 的规范化 `platforms` 字段；
  重复订阅会更新平台筛选而不是创建重复记录。首次订阅或首次成功检查只建立基线，不补发无法确认时间范围的历史更新。
- `notifications.client_update_enabled` 启用后，独立任务按 `notifications.client_update_check_minutes` 检查；
  检测到变化时按平台展示区服、旧版本、新版本和新增更新大小，单个平台失败会记录安全日志并保留其他平台结果。
- OneBot 且 `notifications.client_update_merge_forward` 开启时，同轮多平台消息会尝试合并转发；
  非 OneBot 不受此开关影响，合并失败时降级为逐平台普通消息。

> 客户端更新变化会以 `event_key` 固定首次匹配目标，逐目标记录 `pending`/`delivered`；下一轮先重试未完成目标，
> 取消或停用会清理对应状态，重新订阅不会补发旧事件。

## 签到

- `签到`、`社区签到`、`每日任务`、`社区任务`、`库街区签到`、`sign`：执行当前激活 UID 的签到和配置中的社区任务。
- `签到日历`、`签到记录`、`签到历史`：查看签到日历、积分和社区任务进度。
- `全部签到`：管理员对符合条件的已登录账号执行签到，并返回汇总。
- `开启自动签到`、`关闭自动签到`：开关当前用户当前 UID 的自动签到。
- `订阅签到结果`、`取消订阅签到结果`：开关所有账号、所有群的全局文字汇总推送。
- `订阅本群签到报告`、`取消订阅本群签到报告`：开关当前群的独立签到报告推送，需要 AstrBot 管理员权限，并且必须在群聊中执行。

两套签到订阅彼此独立：同一个群可以只订阅全局汇总、只订阅本群报告，或同时订阅两者。
本群报告只有在 `sign_in.group_report` 开启且当前群已订阅时才会发送；游戏签到和社区签到会分别
生成报告。`sign_in.group_report_image` 关闭时发送本群文字报告，开启时发送本群图片并保留必要
的明细文字；它不影响全局汇总的文字格式。私聊绑定没有群组目标，只计入全局汇总，不会发送到群。

定时签到需要同时开启 `sign_in.scheduled_enabled` 并设置有效的 `sign_in.sign_time`。打开
`sign_in.enable_all_users` 后，定时任务会覆盖所有已登录用户；手动 `全部签到` 不受该开关影响。

## 密函与公告

- `密函`、`委托密函`、`mh`：查看当前时段的密函委托。
- `密函列表`、`mh_list`：查看密函名称列表。
- `公告`：查看公告列表；`公告 1` 查看指定公告详情。
- `订阅<密函名>密函`、`取消订阅<密函名>密函`：订阅或取消指定密函，可使用角色、武器、魔之楔类型前缀。
- `我的密函`、`密函订阅`：查看当前会话的密函订阅。
- `订阅密函时间17:23`、`订阅密函周期17:23`：设置密函推送时间窗口。
- `订阅密函图片`、`取消订阅密函图片`、`订阅密函文本`、`取消订阅密函文本`：切换推送格式。
- `订阅公告`、`取消订阅公告`：管理员开关当前群聊的公告推送。

密函自动推送的时间由 `notifications.secret_push_minute` 控制；公告轮询间隔由
`notifications.announcement_check_minutes` 控制。公告、密函、玩家数据和玩家卡片等内容缓存共用
`cache.ttl_hours`；没有有效订阅时不会发送对应推送。

## 公共资源与别名维护

以下命令需要 AstrBot `ADMIN` 权限：

- `资源状态`：查看公共资源、manifest 和当前 generation 状态。
- `下载全部资源`：同步并校验公共资源；失败时保留上一次可用资源并返回原因。
- `添加角色<角色名>别名<别名>`、`删除角色<角色名>别名<别名>`：维护角色别名。
- `添加武器<武器名>别名<别名>`、`删除武器<武器名>别名<别名>`：维护武器别名。
- `恢复别名`：重新载入默认别名并保留自定义别名。
- `强制恢复别名`：清空角色和武器的自定义别名。

资源目录和同步选项见 [公共资源](resources.md)。默认资源未准备好时，图鉴和攻略命令会返回缺失提示；管理员可以先查看 `资源状态`，再执行 `下载全部资源`。

## 隐私控制

个人命令：

- `开偷窥`、`关闭偷窥防护`：允许他人查看自己的游戏信息。
- `防偷窥`、`开启偷窥防护`：禁止他人查看自己的游戏信息。
- `隐藏UID`、`隐藏uid`：隐藏自己的 UID。
- `显示UID`、`显示uid`：显示自己的 UID。

管理员群聊命令：

- `指定开偷窥`、`指定防偷窥`：设置被 @ 用户的查询权限。
- `全体开偷窥`、`全体防偷窥`、`取消全体偷窥`：设置或取消群组偷窥规则。
- `指定隐藏UID`、`指定显示UID`：设置被 @ 用户的 UID 展示方式。
- `全体隐藏UID`、`全体显示UID`、`取消全体UID隐藏`：设置或取消群组 UID 展示规则。

群组强制规则优先于个人设置；命令在找不到有效的 @ 目标时会明确提示，不会静默改查其他用户。是否允许普通查询使用 @ 目标由 `display.allow_mention_query` 控制。

## 权限说明

- `user`：普通成员可使用的查询、登录、签到和个人设置命令。
- `admin`：需要 AstrBot `ADMIN` 权限的管理命令。

如果命令没有响应，请先发送当前前缀加 `帮助`，再检查插件是否启用和配置是否已重载。
