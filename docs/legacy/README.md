# DNAUID 登录排查归档

日期：2026-07-31 ~ 2026-08-06
范围：DNAUID 插件、皎皎角 Android 客户端 `1.4.0.1` 的已授权静态分析，以及 `atri` 上受控日志、模拟器真机验证与接口行为观察。

## 结论摘要

- 现有登录凭证仍可使用，插件主要功能未整体失效；问题集中在新用户登录与凭证失效后的重新授权。
- 2026-08-06 已定位 `248` 根因：**ct4.js 初始化缺少 native 会话参数**（`clientType: android` + `mi` + `rem`）。
- **服务端方案完全可行，无需导出 App**：桌面浏览器 + App 场景 captchaId + native 参数，`getSmsCode` 200、`sdkLogin` 成功，服务端即可自行发码并登录。插件 Web 登录页改两处即可闭环。
- 端到端已验证：发码 → 输码 → `sdkLogin` → 拿到 `token` + `refreshToken`。

## 工程产物

- `script/`：独立测试登录页（`server.py` + `login.html`），验证了桌面浏览器 + native 参数的完整登录链路。
- `dna-bridge-flutter/`：导出 App（Flutter），WebView + ct4.js + native 参数方案（服务端方案成立后可不再需要）。
  - 签名移植（`sign_130.py`/`sign_utils.py` → Dart）有单元测试。

## 敏感信息处理

本文档不记录手机号、短信验证码、token、refreshToken、`devCode` 原值、设备标识或完整认证请求。示例仅描述字段名称和结果码。
