# 范围与证据

## 授权与边界

- 分析对象：用户提供的 Android APK 与用户控制的测试模拟器。
- 服务端：`atri` 中挂载的 DNAUID 插件源码和 `gsuid_core` 容器日志。
- 不执行 TLS 解密绕过、证书锁定绕过、暴力尝试或未授权账号测试。
- 认证材料只在受控环境中用于验证；文档及日志均不保存原值。

## 版本基线

| 项目 | 值 |
| --- | --- |
| Android 包名 | `com.hero.dna` |
| 客户端版本 | `1.4.0.1`（versionCode `14`） |
| DNAUID 上游提交 | `b679dba` |
| 上游版本描述 | `1.0` |
| 服务容器 | `gsuid_core` |

## 证据等级

### 高置信度

- APK 的 Retrofit 接口声明、登录 Activity、请求签名与设备码实现。
- `atri` 容器产生的 DNAUID 日志。
- 对用户控制测试账号执行的最小、单次接口验证。

### 中等置信度

- 上游错误 `248` 与验证码结果、网络来源或运行环境组合校验有关。这是由“官方 App 可发码、服务端代发失败”的对照推断，服务端未提供细分原因。

### 未覆盖项

- 未对 TLS 流量解密或抓包，因此未声明获得逐字节网络报文。
- 未验证不存在于 APK 当前版本登录界面中的未来官方授权方式。
