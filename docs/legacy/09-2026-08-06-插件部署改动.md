## 关键前提与发现（本次确认）

- **native 会话参数**：`clientType: android`、`mi`（包名任意）、`rem` 是 248 的钥匙；包名不被硬校验。
- **h5 签名被 403 拦截**：插件原 web 发码路径（h5 + Web 场景）无法工作，必须用 android 签名 + App 场景 captchaId。
- **devCode 格式不校验**：64hex / UUID / `"2"+32hex` 均被后端处理；但发码与登录必须一致（否则 151）。
- 桌面浏览器与 Android WebView 均可产出被接受的 vJson。
